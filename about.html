Background & Direction

I started with Python by writing scripts to automate small tasks, solving logic problems, and learning language syntax. As I read more about web application exploitation, attacker methodologies, and how security tooling works under the hood, my focus evolved.

Now every time I write code, I analyze edge cases: What happens with unexpected or malformed input? How is data sanitized? How are session tokens validated? Understanding how software breaks is the foundation of building it right.

The Shift to Engineered Systems

I am transitioning from simple one-off scripts to structured, reusable tools. What I build now incorporates proper error handling, modular architecture, CLI interfaces, and clean documentation.
